## Correção

- **Uma cópia antiga do MouseFix não atrapalha mais a nova.** Se uma versão mais antiga estiver aberta (por exemplo, um `MouseFix.exe` velho na pasta Downloads), a nova fecha essa versão e assume o lugar dela. Antes, a nova desistia e a antiga continuava aplicando as configurações velhas.
- **"Iniciar com o Windows" passa a abrir a versão nova** quando estava apontando para uma cópia mais antiga ou que não existe mais.
- As duas coisas ficam anotadas no **Histórico**.

Abrir a mesma versão duas vezes continua dando uma cópia só, e abrir uma versão mais velha não fecha a mais nova.

## Segurança

- Os arquivos desta versão foram **compilados pelo GitHub Actions** direto do código público e têm **atestação** assinada pelo GitHub. Para conferir: `gh attestation verify MouseFix.exe --repo juancarlos-QW/MouseFix`.
- Cada arquivo tem o seu `.sha256` abaixo.
